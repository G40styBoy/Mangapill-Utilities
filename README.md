[mangapill](https://mangapill.com/) tampermonkey scripts that make the experience of reading free manga even better. Tested on [FireFox](https://www.firefox.com/en-US/download/windows/).

## Installation
  Install [Tampermonkey](https://www.tampermonkey.net/). I would also *highly* recommend the [uBlock Origin](https://addons.mozilla.org/en-US/firefox/addon/ublock-origin/) extension. After these are installed. Click on the `user.js` script you want to install. click `raw`, then you'll be automatically navigated to install the extension.

enjoy!
